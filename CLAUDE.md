## Project
This is an ad tech dashboard being built step by step. It will grow to include data generation, analysis, and visualization of ad campaign metrics (impressions, clicks, spend, CTR, CPM, etc.).

## Code Preferences
- Write simple, readable Python — avoid clever one-liners or unnecessary complexity
- Add comments explaining what each section of code does
- Always use **pandas** for any data manipulation or analysis work
- Always print a confirmation message at the end of every script when it finishes running (e.g. `print("Done. Report complete.")`)

## Libraries in Use
- `pandas` — data manipulation
- `numpy` — data generation
- `matplotlib` — charts and visualizations
